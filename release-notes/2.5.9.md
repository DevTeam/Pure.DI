# Pure.DI - what is new

Version **2.5.9**, compared with the **2.5.8** tag.

## Fix for delegate arguments in dependency cycles

Pure.DI 2.5.8 could generate a reference to a delegate argument outside the lambda that supplied it, causing C# compiler error `CS0103`. This happened when a dependency in a cycle was also reachable directly from a composition root. [#204](https://github.com/DevTeam/Pure.DI/issues/204)

The generator now resolves the dependency using the values available on each path. A path through the delegate can use its argument. A path that bypasses the delegate uses an available binding or reports [`DIE000`](https://github.com/DevTeam/Pure.DI/blob/983c245849c695db186bc2c846e8eac50480a776/DIAGNOSTICS.md#die000) if the dependency cannot be resolved.

## NuGet publishing

- Pushing a stable or prerelease version tag now starts the workflow that builds, validates, and publishes the NuGet packages.
- A manual build without publishing can use the selected branch when the version tag does not exist yet. Manual publishing requires an existing version tag. [Publishing guide](https://github.com/DevTeam/Pure.DI/blob/983c245849c695db186bc2c846e8eac50480a776/CONTRIBUTING.md)
