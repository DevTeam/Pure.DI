# Pure.DI - what is new

Version **2.5.10**, compared with the **2.5.9** tag.

## Less work for the IDE

Previously, the generator ran from scratch after every edit in the IDE. It regenerated every composition and every generated interface, even after an edit inside a method body.

The generator now compares a fingerprint of the compilation with the previous one. The fingerprint covers the full text of files with setups, the declarations in other files without member bodies, the partial declarations of setup types, references and options. When the fingerprint is unchanged, the IDE keeps the previously generated code and diagnostics. While the generator reports a diagnostic in a file without setups, it still runs after every edit, so the diagnostic location stays accurate. Generated interfaces are now handled per class, and their source files are added again only when their contents change. Builds outside the IDE generate the code as before.

## Smaller generated code

The generated `Resolve(Type)` methods no longer contain a separate .NET Core 3.0+ branch for type hash codes. That branch produced the same value as `RuntimeHelpers.GetHashCode` with an extra virtual call.
